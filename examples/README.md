# Examples

This directory contains quickstart inputs and worked examples:

```text
examples/
  quickstart/
  worked_examples/
```

## Quickstart

`quickstart/` contains the small input tables and PDB files used by
`run_saafec_stair_inference.sh` when no input paths are supplied.

## Worked Examples

`worked_examples/` contains runnable single- and double-mutation examples.
Each includes inputs, a run script, and expected outputs from a completed run.
Additional intermediate and diagnostic files are written to the ignored
`run_outputs/` directory.
