# Double-Mutation Validation Set

[01_MegaScale_Validation_Set.xlsx](01_MegaScale_Validation_Set.xlsx) contains 10,672 double-mutation measurements across 17 proteins. It was used for model selection.

The file comes from the ThermoMPNN-D archive (https://doi.org/10.5281/zenodo.13345274), and the protein split follows ThermoMPNN. ΔΔG is reported in kcal/mol using ΔG(mutant) − ΔG(wild type).
