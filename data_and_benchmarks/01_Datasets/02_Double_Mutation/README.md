# Double-Mutation Datasets

| Set | File | Size |
|---|---|---:|
| Training | [01_MegaScale_Training_Set.xlsx](01_Training/01_MegaScale_Training_Set.xlsx) | 122,278 measurements; 116 proteins |
| Validation | [01_MegaScale_Validation_Set.xlsx](02_Validation/01_MegaScale_Validation_Set.xlsx) | 10,672 measurements; 17 proteins |
| Test | [01_MegaScale_Test_Set.xlsx](03_Testing/01_MegaScale_Test_Set.xlsx) | 22,081 measurements; 20 proteins |

The measurements originated from MegaScale and were obtained from the ThermoMPNN-D archive (https://doi.org/10.5281/zenodo.13345274). The protein split follows ThermoMPNN. ΔΔG is reported in kcal/mol using ΔG(mutant) − ΔG(wild type).
