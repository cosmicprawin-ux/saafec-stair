# Double-Mutation Test Set

[01_MegaScale_Test_Set.xlsx](01_MegaScale_Test_Set.xlsx) contains 22,081 double-mutation measurements across 20 proteins. It defines the row order used in the complete double-mutation prediction file.

The file comes from the ThermoMPNN-D archive (https://doi.org/10.5281/zenodo.13345274), and the protein split follows ThermoMPNN. The seven-protein MutateEverything comparison is a separate overlap-control subset. ΔΔG is reported in kcal/mol using ΔG(mutant) − ΔG(wild type).
