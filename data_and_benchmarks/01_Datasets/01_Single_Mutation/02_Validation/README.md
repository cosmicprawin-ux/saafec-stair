# Single-Mutation Validation Sets

| File | Contents |
|---|---|
| [01_MegaScale_Validation_Set.xlsx](01_MegaScale_Validation_Set.xlsx) | Initial validation set: 26,554 mutations across 30 proteins. |
| [02_Transferred_Test_Mutations.xlsx](02_Transferred_Test_Mutations.xlsx) | 1,143 mutations from 25 proteins transferred after the homology check. |
| [03_Final_Validation_Set.xlsx](03_Final_Validation_Set.xlsx) | Final validation set: 27,697 mutations across 55 proteins. |

The final file combines the first two sets. ΔΔG is reported in kcal/mol using ΔG(mutant) − ΔG(wild type).
