| File | Contents |
|---|---|
| [01_Complete_Test_Set_Predictions.xlsx](01_Complete_Test_Set_Predictions.xlsx) | Evaluated methods on 22,081 measurements across 20 proteins. |
| [02_MutateEverything_Overlap-Control_Subset.xlsx](02_MutateEverything_Overlap-Control_Subset.xlsx) | SAAFEC-STAIR and MutateEverything on 4,599 measurements across seven proteins. |

For the overlap control, 13 test proteins whose identifiers occurred in the published MutateEverything cDNA training split were removed. The workbook retains the two predictions, experimental values and an overlap record. This is an identifier-based control rather than a sequence-homology filter.

ΔΔG is reported in kcal/mol using ΔG(mutant) − ΔG(wild type). Missing predictions are shown as `-`.
